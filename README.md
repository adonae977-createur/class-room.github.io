# InfiniCare Studio - Application Mobile PWA pour Instituts Infirmiers

InfiniCare Studio est un portail applicatif frontend mobile-first, conçu pour optimiser, suivre et ludifier (gamification) la scolarité des étudiants en sciences infirmières. L'ergonomie générale s'inspire du framework cognitif de Duolingo, Notion et Google Classroom.

## 🛠️ Stack Technique de Production
* **Core :** React 18, Vite, JavaScript ES6+
* **Routage :** React Router DOM 6
* **Styling & Structure Responsive :** Tailwind CSS, React Icons
* **Moteur d'Animations Fluides :** Framer Motion
* **Gestion d'État Global :** Context API React
* **Interopérabilité :** PWA Ready (Service Worker natif, Web Manifest complet)
